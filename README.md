# Farhan Ahmed Turjoy — Portfolio Website

A responsive static portfolio with smooth hero motion, orbiting portrait rings, subtle ambient background movement, hover micro-interactions, and scroll-triggered reveals.

## Upload to the existing GitHub repository

1. Extract this ZIP on your computer.
2. Open the `Farhan_Portfolio_Smooth` folder.
3. In your GitHub repository, replace `index.html`, `style.css`, and `script.js` with these versions.
4. Open the repository's `assets` folder and upload `Farhan Ahmed Turjoy.jfif` and `Farhan-Ahmed-CV.pdf` (if the CV is not already there).
5. Commit the changes.
6. Wait a few minutes, then refresh the published site with Ctrl + F5.

Keep `index.html`, `style.css`, and `script.js` in the repository root. Keep the photo and CV inside `assets/`.

The portrait is a real JPEG/JFIF image saved with the exact filename `Farhan Ahmed Turjoy.jfif`.
